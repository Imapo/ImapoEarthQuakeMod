# Realistic Earthquake — мод для tModLoader 1.4.4.9

## Что реализовано (по пунктам ТЗ)

1. **Падающие обломки** — `Content/Projectiles/FallingDebris.cs`. Гравитация, отскок от стен
   (`OnTileCollide`), урон при приземлении на игрока.
2. **Пыльное облако + дебафф** — при ударе о землю обломок создаёт пыль и накладывает
   дебафф `DustyHazeDebuff` (`Content/Buffs/DustyHazeDebuff.cs`), который читает
   `EarthquakeVisualsSystem` и рисует полупрозрачную дымку на весь экран — снижает видимость.
3. **Нарастающий гул за 10-15 сек** — `EarthquakeSystem.HandleRumbleSound()`. Каждые ~0.75 сек
   проигрывает импульс звука с растущей громкостью и понижающимся питчем.
4. **Пыль с потолка, чаще в помещении** — `EarthquakeSystem.HandleWarningDust()` +
   `CeilingScanner.IsIndoors()`.
5. **Афтершоки на 2-3 минуты** — фаза `EarthquakeState.Aftershock`, случайные "всплески"
   тряски и редкие обломки.
6. **Реальные блоки не разрушаются** — обломки это **снаряды** (Projectile), не тайлы.
   Настоящий блок в мире не удаляется. Проверка "что над головой" — `CeilingScanner.cs`,
   осыпается только то, что есть в реестре `DebrisMaterials.SoftTiles` (грязь, земля, ил, пепел,
   глина, песок всех видов, песчаник всех видов, лёд всех видов, снег, слякоть). Если первый
   сплошной тайл над головой — камень/руда/что угодно твёрже — ничего не спавнится (укрытие).
7. **Урон от твёрдости породы** — поле `Hardness` в `DebrisMaterial`
   (снег 0.5 → земля/грязь 1.0 → глина 1.25 → пески 1.4 → песчаник 1.8 → лёд 2.0),
   умножается на магнитуду и на конфиг `DebrisDamageMultiplier`.
8. **Сообщения в чат** — `EarthquakeSystem.BroadcastMessage()`, вызывается при начале
   основной фазы и при полном завершении события.
9. **Случайная магнитуда 3-10** — влияет и на силу тряски экрана (`CurrentShakeIntensity`,
   ограничена разумным пределом ~11px), и на частоту спавна обломков.
10. **Настройка периодичности 5-60 минут** — `Common/Configs/EarthquakeConfig.cs`,
    слайдер `AverageIntervalMinutes` (реальный интервал колеблется ±30% для непредсказуемости).
11. **Кнопка ручного вызова** — `Content/UI/EarthquakeUIState.cs` + `EarthquakeUISystem.cs`.
    Кнопка "EQ" в правой части экрана, при клике разворачивается панель с выбором магнитуды 1-10
    и кнопкой "Вызвать!". Можно отключить в конфиге (`ShowDebugButton`).

### Бонусы
- **Сейсмограф** (`Content/Items/Seismograph.cs`) — крафтимый аксессуар (15 камня + 5 жел.
  слитков + золотые часы у наковальни), показывает в углу экрана текущую фазу и обратный
  отсчёт до следующего землетрясения/до конца текущей фазы.
- Простая **сетевая синхронизация** состояния для мультиплеера (`EarthquakeNetHandler.cs`):
  сервер авторитетно ведёт таймер и рассылает состояние клиентам, кнопка ручного вызова
  у обычного клиента отправляет запрос на сервер.
- Магнитуда влияет не только на силу тряски, но и на количество обломков за спавн
  (`maxPerPlayer = 1 + magnitude / 5`).

## Установка проекта

1. Установи tModLoader 1.4.4.9 и открой "Mod Sources" (`Steam/steamapps/common/tModLoader/ModSources` на Windows,
   либо `~/Documents/My Games/Terraria/tModLoader/ModSources` на других системах, если оно уже создавалось раньше — либо
   `~/.local/share/Terraria/tModLoader/ModSources` на Linux).
2. Скопируй папку `RealisticEarthquake` целиком внутрь `ModSources`.
3. В игре: Мастерская модов (Mod Sources) → найди `RealisticEarthquake` в списке → **Build + Reload**.

## На что обратить внимание при первой сборке

Я писал код без доступа к компилятору tModLoader, поэтому пара мест **могут** потребовать
мелкой правки под точную версию API (обычно 1-2 строки):

- **`DustID`**: для глины использован `DustID.Clentaminator_Blue` как временная заглушка —
  замени на подходящий, если найдёшь более точный (например `DustID.Clay`, если он есть в твоей версии).
- **`Terraria.Utils.DrawBorderString`** — если сигнатура отличается, используй
  `Terraria.UI.Chat.ChatManager.DrawColorCodedStringWithShadow` как альтернативу для HUD-текста сейсмографа.
- **Звук гула** — сейчас это `SoundID.Item62` (взрыв) на пониженном питче — рабочая имитация "из коробки".
  Если хочешь настоящий низкочастотный гул: положи `Rumble.ogg` в `RealisticEarthquake/Assets/Sounds/Rumble.ogg`
  и замени строку в `EarthquakeSystem.HandleRumbleSound()` на:
  ```csharp
  SoundEngine.PlaySound(new SoundStyle("RealisticEarthquake/Assets/Sounds/Rumble") { Volume = volume, Pitch = pitch });
  ```
- Иконка мода (`icon.png`, 80×80) для Workshop не добавлена — добавь свою при публикации.
